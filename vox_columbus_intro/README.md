# VOX 스타일 '콜럼버스의 첫 항해' 인트로

> Analog-feeling title system — printed matter that someone cut out and arranged by hand, then photographed.

옛 해도 위에 인쇄물에서 오려낸 배·구름·종이띠를 손으로 배치하고 탁상 조명 아래에서 찍은 것처럼 만든
11초 인트로. 요소 이미지는 전부 Kling 으로 만들고, 3D 카메라·합성·타이포는 파이썬으로 했다.

결과물: `output/columbus_1492_intro.mp4` (1920x1080, 24fps, 11초) · `output/poster.png`

```bash
cd vox_columbus_intro
pip install numpy pillow opencv-python-headless   # ffmpeg 도 필요
python cutouts.py        # Kling 원본 → 손으로 오린 종이 컷아웃 (assets/cut_*.png)
python intro.py          # → output/columbus_1492_intro.mp4 (약 3분)
python intro.py --preview 0.5,3.8,6.0   # 정지 프레임만 확인
```

| 5.3s– | `1492` 컷아웃, `THE FIRST VOYAGE OF COLUMBUS` 종이띠가 손으로 눌러 붙이듯 놓임 | 타이틀 |
| 9.7s– | `GUANAHANI · 12 OCT 1492` 태그 | 도착 |

**아날로그 규칙 (프롬프트 제작법 반영)**
- 디지털 모션그래픽 요소 없음: 글자는 전부 종이(오린 컷아웃 / 찢어진 종이띠 / 해도 위 라벨)에 '인쇄'된 상태로만 등장.
- 모든 컷아웃은 가위로 오린 다각형 윤곽 + 크림색 종이 여백, 밧줄 사이처럼 좁은 틈은 종이째 남김.
- 요소는 초당 12장으로 끊어 움직임 (스톱모션), 카메라만 부드럽게.
- 사진 마감: 왼쪽 위 스탠드 조명, 비네팅, 노출 깜빡임, 필름 그레인, 카메라 미세 흔들림, 틸트시프트 심도.
- 사람 형상 없음 — 배·지도·구름·문서만으로 이야기.

해도는 생성 이미지라 실제 지리와 다르다. 항로 좌표(`ROUTE`)는 그림 위 이베리아 남서 해안·아프리카 앞바다·

## 구현 메모

- **카메라**: 핀홀 카메라(가로 화각 약 40°)로 해도면을 투영. 해도·구름·배·태그는 모두 평면이라 꼭짓점 4개를 투영해 호모그래피로 그린다.
- **배가 해도에서 나오는 원리**: 배 컷아웃은 해도에 20° 뒤로 기대 선 평면. 스프라이트 좌표마다 해도면 위 높이 z 를 계산해 z<0(해도 아래)은 지운다 → 흘수선이 해도면과 정확히 만나는 칼집처럼 보임. 솟는 양은 감쇠 스프링(ζ=0.42)이라 한 번 넘쳤다가 살짝 들어간다.
- **그림자**: 북서쪽 조명 방향으로 각 평면을 해도에 투사해서 흐림. 높이 떠 있는 구름일수록 멀리·부드럽게.
- **키잉**: Kling 이 이미지마다 다른 초록(탁한 인쇄 초록 a*≈-17 ~ 형광 초록 a*≈-52)을 깔아서, 테두리로 배경 a* 를 추정해 문턱을 잡는다.
- **폰트**: Old Standard TT (1492), IM Fell English SC (부제), Courier Prime (날짜 태그). 모두 OFL, `fonts/`.

## 자주 바꾸는 값 (`intro.py` 상단)

`TILT`(기울기), `SHIP_UP`(배 등장 시각), `SHIP_LEN`, `SHIP_LEAN`, `CLOUDS`(위치·높이·크기), `WIND`, `ROUTE`, `ON_TWOS`(스톱모션 끄기/켜기)
