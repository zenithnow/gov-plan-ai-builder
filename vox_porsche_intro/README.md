# VOX 스타일 포르쉐 718 박스터 인트로

버드뷰로 스카이블루 박스터가 빠르게 들어오다가, 드리프트에 들어가는 순간 슬로우모션이 걸리고
타이어 자국을 남기며 멈춘다. 그 사이 `PORSCHE / 718 / BOXSTER` 타이포가 슬롯에서 튀어 오른다.

결과물: `output/porsche_718_intro.mp4` (1920x1080, 30fps, 6초) · `output/poster.png` (마지막 장면)

```bash
cd vox_porsche_intro
pip install numpy pillow opencv-python-headless   # ffmpeg 도 필요
python intro.py                                   # → output/porsche_718_intro.mp4 (약 1분)
python intro.py --preview 0.5,1.2,5.5             # 지정 시각의 정지 프레임만 PNG 로 (수정 확인용)
```

## 타임라인

| 영상 시간 | 장면 |
|-----------|------|
| 0.0 – 0.58s | 화면 왼쪽에서 빠르게 진입 (모션블러, 속도선, 카메라 흔들림) |
| 0.58 – 0.78s | 재생 속도 1.0 → 0.11 로 급감속 + 살짝 밀고 들어가는 줌 펀치 |
| 0.78 – 3.5s | 슬로우모션 드리프트: 차가 최대 42° 미끄러지며 돌고, 뒷바퀴 자국·종이 컷 연기 |
| 1.25s – | `718` 이 슬롯에서 스프링처럼 튀어 오름 |
| 1.60s – | `BOXSTER` 글자들이 한 자씩 엇박으로 튀어 오름 |
| 2.05s – | 노란 형광펜 띠가 BOXSTER 뒤를 왼→오로 칠함 |
| 2.35s – | `PORSCHE` + 가는 선 |
| 3.5 – 6.0s | 정지, 타이틀 홀드 (천천히 줌인 유지) |

## 만든 방식

**Kling (이미지 2장, `kling_assets.json` 에 프롬프트·URL)**
- `assets/car_raw.png` – 마젠타 배경 위 정확한 탑다운 박스터 (앞머리 오른쪽). 파이썬에서 회전시키기 쉽게 수평으로.
- `assets/bg_raw.png` – 옅은 하늘색 종이 질감 바닥.

**파이썬 (`intro.py`)**
- **키잉**: Kling 이 순수 마젠타 대신 그라데이션 크림슨을 깔아서, Lab a* 채널과 밝기로 나눈 붉은 정도로 배경과 차 밑 그림자를 뺀다. 결과는 `assets/car_cutout.png` 로 캐시.
- **배경색**: Kling 배경의 종이 질감(밝기 변화)만 살리고, 색은 차 도장색(90,162,183)을 흰색 쪽으로 55% 섞은 하늘색으로 통일.
- **궤적**: 직선 → 원호. 원호에서 감속하며 슬립각이 0 → 42° 로 커지고, 차 방향 = 진행 방향 − 슬립각.
- **슬로우모션**: 영상 시간마다 재생 배율 `SLOWMO` 를 적분해서 물리 시간을 구한다. 차가 원호에 들어가는 순간 배율이 0.13 근처가 되도록 맞춤.
- **타이어 자국**: 718 박스터 비율(휠베이스 2.475m)로 잡은 뒷바퀴 위치를 3px 간격으로 이어 그림. 슬립각이 클수록 진하게.
- **VOX 질감**: 흰 스티커 테두리 + 오프셋 그림자 컷아웃, 3단으로 끊은 종이 컷 연기, 노란 형광펜, 초당 12번 바뀌는 종이 결·그레인, 글자 미세 흔들림, 비네팅.
- **타이포**: Archivo (OFL, `fonts/`) 가변 폰트. 718 은 Black, BOXSTER 는 Expanded Black, PORSCHE 는 Expanded SemiBold + 넓은 자간.

## 자주 바꾸는 값 (`intro.py` 상단)

| 값 | 설명 |
|----|------|
| `SLOWMO` | (영상시간, 재생배율) 목록. 0.11 을 낮추면 더 느린 슬로우 |
| `V0`, `RADIUS`, `STOP_ANGLE`, `BETA_MAX` | 진입 속도, 드리프트 반경, 도는 각도, 최대 슬립각 |
| `T_718`, `T_BOXSTER`, `T_BAR`, `T_PORSCHE` | 타이포 등장 시각 |
| `BG_TINT`, `INK`, `HIGHLIGHT` | 배경색, 잉크(글자·자국)색, 형광펜색 |
| `CAR_LEN` | 화면 위 차 길이(px) |
